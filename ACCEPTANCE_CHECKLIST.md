# Приёмочный чек-лист TOPGUN · Мой день v0.2

Дата фиксации: 2026-08-27  
Статус: пользовательская приёмка пройдена; стабильная контрольная версия создана.

## Продуктовый сценарий

- [x] **Synthetic demo** — `data/demo_topgun_v02.xlsx` определяется как
  `SYNTHETIC_V02` и помечается как `SYNTHETIC DEMO DATA`.
- [x] **Legacy compatibility** — `data/demo_topgun.xlsx` загружается как
  `LEGACY_V01` без изменения исходного файла.
- [x] **Четыре KPI** — доступны средний чек, визиты с допуслугой, продажи
  товаров и предварительная запись для synthetic demo.
- [x] **Самосравнение мастера** — current и previous содержат непосредственно
  следующие друг за другом непересекающиеся периоды одинаковой длины.
- [x] **Нейтральная аналитика** — выводятся факты и дельты без оценок,
  нормативов и автоматически придуманных рекомендаций.
- [x] **DATA GAP** — недоступная метрика не превращается в ноль; legacy
  допуслуга показывает короткое сообщение на основном экране, полный reason —
  в «Методике и ограничениях».
- [x] **Ориентир** — используется только `NOT_CONFIGURED`; не подставляются
  командные, филиальные или категорийные базы сравнения.
- [x] **Бизнес-правила** — `config/business_rules.json` является единственным
  исполняемым источником; end-to-end DRAFT → ACTIVE проверен во временном JSON,
  а рабочая конфигурация содержит 0 правил и 0 `ACTIVE`.
- [x] **Интерактивный интерфейс** — четыре KPI-карточки выбирают одну
  подробную «Динамику показателя» с previous/current-барами и нейтральной
  дельтой.
- [x] **Responsive** — KPI остаются 2×2, а динамика, контекст и нижние блоки
  переходят в вертикальную компоновку около 760 px без горизонтального скролла.
- [x] **HTML-экспорт** — автономный UTF-8 HTML не содержит `client_id`,
  `visit_id`, строк визитов, JSON или внутренних деталей правил; перезапись
  требует подтверждения.

# Приёмочный чек-лист TOPGUN · Мой день v0.1

Дата фиксации: 2026-08-10  
Статус: пользовательская проверка пройдена.

- [x] **Запуск двойным кликом** — `run_app.bat` открывает локальное приложение.
- [x] **Загрузка XLSX** — `data/demo_topgun.xlsx` читается, рабочий лист `Визиты` находится автоматически.
- [x] **Выбор барбера** — список заполняется из загруженного файла, выбранный барбер участвует в расчёте.
- [x] **Периоды 1/7/14 дней** — доступны последний день, последние 7 и последние 14 календарных дней.
- [x] **KPI** — рассчитываются визиты, выручка, средний чек, следующая запись, товары/визит и оценка при наличии данных.
- [x] **Сравнение с собой** — используется непосредственно предыдущий сопоставимый период той же длины.
- [x] **Сравнение с командой** — используется агрегат всех визитов команды за тот же период и выбранный филиал.
- [x] **Сильная сторона** — определяется максимальная положительная дельта не менее 5% либо показывается стабильный период.
- [x] **Зона внимания** — определяется максимальное снижение не менее 5% либо сообщается об отсутствии выраженного снижения.
- [x] **Рекомендация** — показывается один фокус из прозрачной библиотеки правил без LLM/API.
- [x] **HTML-экспорт** — создаётся автономный печатный отчёт без клиентских строк, перезапись требует подтверждения.
- [x] **Понятная ошибка при некорректном файле** — отсутствующие поля и неверные даты, числа или значения «Да/Нет» объясняются по-русски.

## Контрольная проверка

- [x] GUI-smoke на `data/demo_topgun.xlsx` пройден.
- [x] Исходные файлы в `data/` и `references/` не изменены.
