# TOPGUN · Мой день для Mac

Это локальное приложение: оно работает без сети и не отправляет вашу выгрузку
внешним сервисам.

## Как открыть

1. Скачайте архив `TOPGUN_MyDay-macos-…zip` и дважды щёлкните по нему.
2. Переместите появившееся приложение **TOPGUN Мой день** в папку
   «Программы» — так его будет легко найти позже.
3. При первом запуске зажмите `Control`, щёлкните по приложению и выберите
   «Открыть», затем ещё раз «Открыть» в окне macOS. Это нужно один раз,
   потому что приложение предназначено для внутреннего использования и не
   подписано Apple.
4. Далее запускайте приложение обычным двойным щелчком.

## Как сделать разбор

1. Нажмите «Выбрать XLSX / CSV» и выберите выгрузку.
2. Выберите мастера, период и филиал, затем нажмите «Собрать разбор».
3. Нажмите «Сохранить отчёт» и выберите нужную папку. По умолчанию откроется
   папка «Документы»; исходная таблица не изменяется.

Если macOS всё равно не даёт открыть приложение, не отключайте защиту системы
целиком. Напишите человеку, который передал архив, и приложите скриншот окна.

## Важно

Архив собирается отдельно для Apple Silicon (`arm64`) и Intel (`x86_64`).
Используйте архив, который соответствует вашему MacBook.
