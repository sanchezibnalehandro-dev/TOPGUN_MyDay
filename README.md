# TOPGUN · Мой день v0.2

Локальный демонстрационный прототип для понятного персонального разбора
результатов барбера по XLSX/CSV. Данные обрабатываются только на компьютере
пользователя и не отправляются во внешние сервисы.

## Что умеет v0.2

- загружает два известных демонстрационных профиля: `LEGACY_V01` и
  `SYNTHETIC_V02`;
- показывает synthetic demo как `SYNTHETIC DEMO DATA`, не выдавая его структуру
  и формулы за методику «Заботы»;
- для synthetic demo рассчитывает средний чек, визиты с допуслугой, продажи
  товаров и предварительную запись;
- сравнивает мастера с самим собой: текущий период с непосредственно
  предшествующим сопоставимым периодом;
- показывает нейтральные факты, current/previous и дельты без оценок,
  нормативов или автоматически придуманных рекомендаций;
- явно показывает `DATA_GAP` и недостаток данных;
- поддерживает интерактивный выбор KPI и подробную «Динамику показателя»;
- сохраняет автономный HTML-отчёт без клиентских идентификаторов и строк
  визитов.

`config/business_rules.json` — единственный исполняемый источник
бизнес-правил. В стабильной v0.2 он содержит пустой список `rules`, поэтому
«Зона внимания» и «Фокус» не делают автоматических оценочных выводов.

## Запуск для пользователя

### Windows

Для обычного запуска дважды щёлкните `run_app.bat`.

На текущем компьютере:

```powershell
& "$env:LocalAppData\Programs\Python\Python312\python.exe" app.py
```

### macOS

Для MacBook передаётся отдельный архив
`TOPGUN_MyDay-macos-arm64.zip` или `TOPGUN_MyDay-macos-x86_64.zip`.
Распакуйте его, перетащите **TOPGUN Мой день** в «Программы» и откройте.
При первом запуске зажмите `Control`, щёлкните по приложению, выберите
«Открыть» и подтвердите действие. Далее приложение запускается двойным
щелчком; Python и команды пользователю не нужны.

Подробная памятка для получателя: `MACOS_HANDOFF.md`.

## Запуск из исходников и сборка

Для запуска исходников на Windows требуется Python 3.12 с Tkinter и
зависимости из `requirements.txt`.

Для чистой установки на другом компьютере из папки проекта:

```powershell
$pythonExe = "$env:LocalAppData\Programs\Python\Python312\python.exe"
& $pythonExe -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv\Scripts\python.exe app.py
```

Сборка macOS выполняется только на MacBook с Python 3.12:

```bash
bash scripts/build_macos_app.sh
```

Скрипт создаёт внутреннюю неподписанную `.app`, затем архив в `dist-macos/`.
Перед передачей откройте приложение на этом MacBook, пройдите сценарий из
раздела «Проверка» и передавайте пользователю именно ZIP-архив. Для разных
архитектур MacBook собирайте отдельные архивы.

## Демо-файлы

### v0.2 synthetic demo

`data/demo_topgun_v02.xlsx`

- 112 синтетических визитов;
- 2 синтетических мастера;
- 28 календарных дней, anchor date: 09.08.2026;
- рабочий лист: `Визиты_SYNTHETIC`.

Используйте его для демонстрации четырёх KPI и сравнения периодов 1, 7 и 14
дней. Реальные поля и формулы «Заботы» остаются DATA GAP до подтверждения.

### legacy demo v0.1

`data/demo_topgun.xlsx`

Файл продолжает загружаться как `LEGACY_V01`: 833 строки, 6 барберов,
2 филиала, период 13.07.2026–09.08.2026, лист `Визиты`.

Legacy-формулы не считаются подтверждённой методикой «Заботы». Например,
«Визиты с допуслугой» для этого формата показываются как DATA GAP.

## Форматы и ограничения

Поддерживаются только явно известные сигнатуры форматов. Приложение не делает
fuzzy matching и не угадывает структуру реальной выгрузки.

Для synthetic demo используются поля:

`date`, `barber`, `visit_id`, `client_id`, `branch`, `service_revenue`,
`product_revenue`, `has_extra_service`, `prebooked`.

CSV legacy поддерживает UTF-8, UTF-8 BOM и Windows-1251, а также запятую,
точку с запятой и табуляцию. Значения идентификаторов synthetic CSV сохраняют
ведущие нули.

Основные известные ограничения записаны в `DATA_GAPS.md`. В v0.2 нет
CRM-интеграции, сервера, базы данных, облака, авторизации, рейтингов,
кадровых рекомендаций, LLM/API, прогнозирования и прямого PDF-экспорта.
HTML можно распечатать в PDF средствами браузера.

## Проверка

```powershell
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
& .\.venv\Scripts\python.exe app.py --smoke-ui
```

Для smoke двух профилей загрузите по очереди `data/demo_topgun.xlsx` и
`data/demo_topgun_v02.xlsx`, выберите мастера и нажмите «Собрать разбор».

Стабильная контрольная версия v0.2 находится в
`backups/TOPGUN_MyDay_v0.2_stable.zip`; рядом расположен её SHA-256-файл.
